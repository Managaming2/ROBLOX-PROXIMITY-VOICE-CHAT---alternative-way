# Roblox Proximity Voice Chat (Alternative Web)

Une application web externe permettant d'utiliser un chat vocal de proximité (ou un salon vocal en direct) avec tes amis tout en jouant à Roblox, sans avoir besoin de passer par le système vocal officiel de la plateforme.

## 🌐 Accéder à l'application

Le site est hébergé directement via GitHub Pages :
👉 **[Ouvrir le salon vocal](https://managaming2.github.io/ROBLOX-PROXIMITY-VOICE-CHAT---alternative-way/)**

## ✨ Fonctionnalités

- **100 % Web :** Aucune installation requise sur téléphone ou PC, fonctionne directement depuis le navigateur.
- **Utilisation en parallèle :** Conçu pour tourner en arrière-plan pendant tes sessions de jeu sur Roblox.
- **Léger et rapide :** Interface simple pour rejoindre un salon et discuter instantanément.

## 🚀 Comment l'utiliser

1. Ouvre le lien du site dans ton navigateur (Chrome, Safari, etc.).
2. Autorise l'accès à ton **microphone** lorsque le navigateur te le demande.
3. Partage le lien ou l'identifiant du salon avec tes amis.
4. Lance **Roblox** et garde la page ouverte en arrière-plan pour discuter en jouant.

## 🛠️ Hébergement et déploiement

Ce projet est hébergé gratuitement sur **GitHub Pages** depuis la branche `main`.
